## Data Files

### Culture Example

Dataset used in Chapter 5 of the book [Geometric Data Analysis](/en/livres) (2004).

[Excel EN](/data/Culture_en.xls) · [Excel FR](/data/Culture_fr.xls) · [SPAD project](/data/Culture_2004.spad) — performs data coding and Multiple Correspondence Analysis (MCA).

### French Worker Survey

Dataset used in the chapter [Interpreting Axes in MCA](/data/Int_Axes.pdf) (1998).

[Excel](/data/Workers.xls) · [SPAD project](/data/FrenchWorkers_2019.spad)

### Leisure Dataset

Dataset used in the book [Analyse géométrique des données multidimensionnelles](/en/livres) (2014).

[Excel](/data/Leisure.xls) · [Description of the dataset](/data/Leisure_data.pdf)

### Parkinson Dataset

Dataset used in the books [Combinatorial Inference in GDA](/en/livres/cigda) (2019), [Analyse géométrique des données multidimensionnelles](/en/livres) (2014) and [Geometric Data Analysis](/en/livres) (2004), and in the paper *Combinatorial Typicality Test in GDA* (2017).

[Excel](/data/Parkinson.xls)

### Political Space Dataset

Data on the political space of French voters at the end of the 1990s, used in the paper [L'espace politique des électeurs français à la fin des années 1990](/data/rfsp_2000.pdf) (2000) and in [Geometric Data Analysis](/en/livres) (Chapter 9, 2004).

[Excel](/data/Political_Space97.xls) · [SPSS file](/data/Political_Space97.sav)

### Taste Example

Dataset used in the monograph [Multiple Correspondence Analysis](/en/livres/mca) (2010).

[Excel](/data/Taste_Example.xls) · [Archived SPAD project](/data/TasteExample.spad)

## Software — R Scripts

The [SPAD](http://www.coheris.com/produits/analytics/logiciel-data-mining/coheris-analytics-spad/) software includes a very comprehensive module for methods of *Geometric Data Analysis* (bi-weighted PCA, specific MCA, concentration ellipses, interpretation of axes using the method of contributions, etc.) as well as efficient tools for exploring *textual data*.

**R scripts** — To download the R scripts for *Combinatorial Inference* methods and the R scripts interfaced with SPAD software, see the [Combinatorial Inference in GDA](/en/livres/cigda) book page.
