## Logiciels — Scripts R

Le logiciel [SPAD](http://www.coheris.com/produits/analytics/logiciel-data-mining/coheris-analytics-spad/) contient un module très complet sur les méthodes d'*analyse géométrique des données* (ACP biponderée, ACM spécifique, ellipses de concentration, interprétation par la méthode des contributions, etc.) ainsi qu'un module performant d'*analyse des données textuelles*.

**Scripts R** — Pour télécharger les scripts R des méthodes d'*inférence combinatoire* et les scripts R interfacés avec le logiciel SPAD, consulter la page du livre [Combinatorial Inference in GDA](/livres/cigda).
